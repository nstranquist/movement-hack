The Problem

AI agents are getting financial autonomy.
How do you trust them?

  • 🤖
    Agents can spend money — wallets, on-chain signing, DeFi interactions are table stakes now.
  • 🚫
    App-level limits aren't enough — code can be bypassed, servers compromised, logic has bugs.
  • ❓
    No cryptographic proof of constraint — you trust the developer's promise, not math.
Solution

BountyMove

A decentralized bounty board where a Claude AI agent autonomously hunts and claims rewards — with limits enforced by the Move VM, not app code.

📋

Post Bounties

Creators lock MOVE in escrow on-chain. Released only on approval.

🤖

Agent Hunts

Claude autonomously claims bounties — but only up to its on-chain cap.

⛓️

VM Enforces

Over-limit claims abort at the VM level. No override. No escape.

The Guardrail

Six lines. Unbreakable.

// bounty_board.move — inside claim_bounty() if (hunter_addr == board.agent_address) { assert!( bounty.bounty_amount <= board.max_claim_amount, E_AGENT_EXCEEDS_MAX // abort code 9 ); };

Runs inside the Move VM on every validator. No server, no middleware, no escape hatch.
