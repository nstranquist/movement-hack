## CLI Commands Reference

```bash
# Working directory for all CLI commands:
cd /Users/nicostran/_eth-denver/movement-hackathon/submission/bounty_board

# Check balance
movement account balance --url https://testnet.movementnetwork.xyz/v1 --account default

# Create bounty (hex-encode title/description)
movement move run \
  --function-id "0xbd573c130b74f71bf82356cc87c0ee0d6228e423c370b7f5b4a009534bac7401::bounty_board::create_bounty" \
  --args "hex:<title_hex>" "hex:<desc_hex>" u64:<octas> \
  --assume-yes

# Claim bounty (as agent)
movement move run \
  --function-id "0xbd573c130b74f71bf82356cc87c0ee0d6228e423c370b7f5b4a009534bac7401::bounty_board::claim_bounty" \
  --args u64:<bounty_id> \
  --assume-yes

# Submit work (as agent)
movement move run \
  --function-id "0xbd573c130b74f71bf82356cc87c0ee0d6228e423c370b7f5b4a009534bac7401::bounty_board::submit_bounty" \
  --args u64:<bounty_id> "hex:<note_hex>" \
  --assume-yes

# View all bounties
movement move view \
  --function-id "0xbd573c130b74f71bf82356cc87c0ee0d6228e423c370b7f5b4a009534bac7401::bounty_board::get_all_bounties"
```

## Demo Script (for judges)

1. **Setup visible:** frontend open at localhost:3001, terminal open in `submission/bounty_board/`
2. Show agent panel: agent address, 0.05 MOVE cap, "Active" status
3. Human (browser) creates a 0.01 MOVE bounty — "Write a haiku about Movement"
4. Agent (terminal) claims it → frontend auto-refreshes in 5s, shows status = Claimed
5. Agent submits a haiku as the work note
6. Human approves in browser → escrow releases → Completed
7. **THE PITCH:** Human creates a 0.1 MOVE bounty → Agent tries to claim → terminal shows `E_AGENT_EXCEEDS_MAX`
8. "The Move VM rejected this transaction mathematically. No app logic, no API — the contract enforces the guardrail."
